# **Проект: vkurse-media**
Демонстрационный сайт, включающий титульную страницу и страницу с новостными блоками. Проект демонстрирует продуманную визуальную подачу контента за счёт сочетания современных CSS‑техник и интерактивных эффектов.

## **Основные возможности**
* **Титульная страница** — с акцентом на визуальную выразительность: реализованы CSS‑анимации, делающие появление элементов динамичным и привлекательным.
* **Страница с новостными блоками** — структурированное отображение контента с удобной компоновкой.
* **Лоадер** — интегрирован на страницу для улучшения пользовательского опыта в момент загрузки данных.

## **Используемые технологии и приёмы**
* **CSS Flexbox и Grid** — для гибкой и адаптивной разметки, позволяющей корректно отображать контент на разных устройствах.
* **CSS‑анимации** — включая плавные эффекты появления и трансформации элементов.
* **Микроанимации (hover, active и другие)** — для повышения интерактивности интерфейса и улучшения отклика на действия пользователя.

Проект подойдёт в качестве референса по работе с CSS‑анимациями, компоновкой на Flexbox/Grid и реализации простых UX‑элементов вроде лоадера.
